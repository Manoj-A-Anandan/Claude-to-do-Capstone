# user-story/

Drop the user story here (`.md`, `.txt`, `.docx`, or `.pdf`), then run `/run-sdlc` with the **sdlc-orchestrator** agent.

If the story lives in JIRA or Confluence, skip this folder and give the orchestrator the key or URL (needs an Atlassian MCP server) or paste the text.

`_extracted.md` is generated by the intake skill; do not edit it.
